# Python Programming

## What Is Python?

Python is a **programming language** used to give instructions to computers and robots. It is popular because its commands are easy to read and understand.

## Why Do We Use Python with mBot2?

We use Python to control the robot and give it different instructions. We can make it display text, change LED colours, and perform different actions.

## What Is a Python Comment?

A Python comment is a note written in the code to explain what a command does. Comments begin with the # symbol.

Example:

```python
# Display a welcome message
```

## Displaying Text on a Screen

Displaying text allows the robot to show messages and information. For example, we can display our name or a welcome message.

Python is useful for creating *simple and interactive programs*.

We can use Python to:
- Display messages.
- Control LED colours.
- Clear the robot's screen.

## Three Examples of Python Code

1. Display text:

```python
cyberpi.display.show_label("Hello!", 16, 0, 0, 0)
```

2. Turn on a red LED:

```python
cyberpi.led.on("red")
```

3. Clear the screen:

```python
cyberpi.display.clear()
```
